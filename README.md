# AIHubBot 🤖

AIHubBot — Telegram-бот с интеграцией искусственного интеллекта.

Проект создан для удобного доступа к AI-инструментам через Telegram. 
Бот будет поддерживать работу с ИИ, систему пользователей, кредиты и дополнительные функции.

## 🚀 Возможности

На данный момент в разработке:

- 🤖 Общение с AI
- 👤 Система пользователей
- 📊 Профиль пользователя
- 💳 Система кредитов
- 📄 Работа с документами
- 🛠 Админ-панель
- 💬 Обработка сообщений
